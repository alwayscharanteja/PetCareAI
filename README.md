# 🐾 PetCareAI – Smart Pet Wellness Tracker

PetCareAI is a Python-based desktop application designed to help pet owners efficiently manage their pets' health and daily activities. The application provides an intuitive interface to maintain pet profiles, medical records, nutrition plans, activity logs, reminders, and health reports in one place.

---

## 📌 Features

- 🐶 Pet Profile Management
  - Add, update, view, and delete pet details
  - Store species, breed, age, weight, and owner information

- 💉 Medical Records
  - Track vaccinations
  - Maintain medical history
  - Record medications and treatment details

- 🥗 Nutrition Management
  - Record daily food intake
  - Track water consumption
  - Monitor calorie intake

- 🏃 Activity Tracking
  - Log daily activities
  - Record exercise duration
  - Monitor pet wellness trends

- ⏰ Reminder Management
  - Vaccination reminders
  - Medication reminders
  - Routine check-up reminders

- 📊 Health Reports
  - Generate pet health reports
  - View stored records
  - Export reports

- 💾 Database Management
  - Securely store pet information using SQLite
  - Easy data retrieval and updates

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Pavitra2005/PetCareAI.git
```

### Navigate to the Project

```bash
cd PetCareAI
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python main.py
```
